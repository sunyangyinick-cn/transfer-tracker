# Transfer Tracker (built site)

The published build of a CS 124 student project: a tracker of real summer 2026 football transfers.
This repository holds only the built website, served by GitHub Pages at
https://sunyangyinick-cn.github.io/transfer-tracker/. The source is kept elsewhere.

Club crests are loaded from Wikimedia; each crest links to its file page with its licence and
credit. Most are non-free files that Wikipedia uses under its own fair-use rationale, which does
not grant permission to this site. Crests are the clubs' trademarks, shown only to identify them.
